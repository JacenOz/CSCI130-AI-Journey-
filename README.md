# CSCI130-AI-Journey
My journey learning AI at NDSCS

## Week 1: Environment Setup and Simple Reflex Agent

### What I Learned
This week, I set up my development environment with Python, VS Code, and Git. I also built my first "AI" program: a simple reflex agent. Even though I have used Python before for projects like my stream automation scripts, this project highlighted how a basic program can be classified as a reflex agent if it takes percepts (like the time of day and user input) and maps them directly to actions (responses) without any memory or learning capabilities. It is the foundational building block of agent design.

### Challenges
The main challenge was making sure the environment setup was clean and properly documented with screenshots for the assignment. I also had to think carefully about how to expand the reflex agent's rule base to catch more mood keywords so it felt slightly more responsive to different user inputs, ensuring it still followed strict `if/elif` heuristic logic.
